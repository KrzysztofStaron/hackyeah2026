# Stage rules

These two decks share one language. A judge who saw the bank can read the clinic without a new legend.

## The unit is a chain

Every beat is a line of events, left to right.

- **Ask.** What the person typed.
- **Tool.** The name the agent called, and the arguments that mattered.
- **Result.** What came back, when a tool ran.
- **Gate.** What the proxy did.

Do not narrate the architecture. The chain is the architecture.

## The card sits next to a stop

A prevented tool is never left hanging. The right column is a card with two lines.

- **Wanted.** The act the agent tried.
- **Did.** What actually happened. Who was on the line. What did not leave. Whether the session ended.

A hard stop ends the session. The agent does not get a second turn. Say that.

A stop is never only a code. The code sits under the sentence.

## Three marks

- **Allow.** Olive. The call finished.
- **Rewrite.** Gold. The call continued. The matched field is `[REDACTED]`. Show the record.
- **Stop.** Crimson. The chain ends. The card names the act that did not happen.

## Payload

When the beat is about data, show a record. The card says the rule in one sentence. An algorithm intercepts any PII before it hits the agent context, unless that field has an explicit allow.

```json
{
  "name": "kamil",
  "last_name": "ślimak",
  "pesel": "[REDACTED]"
}
```

The field is still there. The value is gone.

## Graph

One morning, one bar chart. Allowed. Rewritten. Stopped. The numbers are from the run.

## Motion

Nodes arrive in order, under 200ms each. The card is already there. A stop does not linger. Nothing loops. Nothing uses a blue or purple wash.

## Voice

Present tense. Short sentences. Tools as the agent wrote them.
