POST /v1/chat/completions

handle() in pipeline.py. The agent does not change. It sets base_url to this proxy and sends X-Agent-Id. Every exit, including a pass, appends one line to data/audit.jsonl.

1

Reload the catalog

refresh(POLICY_PATH) and refresh(SIGNATURES_PATH) run on this request. A file that fails to parse returns the last good copy of that path. Both missing returns a block.

403 policy.invalid

No last-good copy for one of the two files.

2

Gate the caller. No text is read yet.

  • Header missing → agent.missing
  • Id not in policy.agents → agent.unknown
  • enabled: false → agent.disabled
  • body.model not in policy.models → model.unknown
  • A tool name not in that agent's tools → tool.denied

Tool names are collected from body.tools, from tool_calls, and from a role: tool message's name.

403 before OpenAI

The body is not forwarded. Tokens stay 0.

3

Split messages into spans

Each span is (text, target, json path). The path is how a rewrite is written back into the same object.

  • content on user, system, or assistant → target prompt
  • content on role: tool → target tool_result
  • tool_calls[].function.arguments, a string → target tool_args

No exit here

Splitting does not decide. The next step does.

4

Scan each span, in this order, on the text so far

  • data_email. Regex [A-Za-z0-9._%+\-]+@[A-Za-z0-9.\-]+\.[A-Za-z]{2,}. Policy action redact replaces the match. Action block stops the request. Standard redacts. Strict blocks.
  • data_secret. sk- plus 20 characters, or a PEM PRIVATE KEY header. Standard blocks the request.
  • signatures, in file order, only if span.target is in that row's target. A block returns immediately. A redact substitutes [REDACTED] and the next signature sees the new text.

Rows in signatures.json: exec and pickle and model_host on tool_args. ignore_previous on prompt and tool_result. pesel (\b\d{11}\b) on all four targets, action redact. model_host matches an http URL whose hostname is not github.com or huggingface.co.

403 or a rewrite

block first Block in span order wins. The request stops.

redact matched spans are written back with _put(body, path, text). The decision stays redact and the call continues.

5

Jev on the inbound text, after redaction

Skipped when controls.jev.enabled is false. tool_args are never sent. One POST to https://ai-gateway.vercel.sh/v1/evaluate, model typesafe-ai/jev, timeout 2s.

  • All prompt spans are joined with newlines and scored once.
  • Each tool_result is scored on its own.
  • State is {direction, text}. Questions are instruction_override and data_exfiltration, each a boolean probability.

judge(): probability at or above the policy threshold and action block → jev.<name>. Probability in 0.4–0.6 while still under the threshold → jev.uncertain. No probabilities → jev.error. Standard thresholds are 0.8. Strict thresholds are 0.6.

403 jev.*

Jev sees [REDACTED], not the original email, key, or 11-digit id.

6

Budget, then OpenAI

Read data/budget.json. If spent.usd >= agents[id].usd_cap, stop. Otherwise complete(body) forwards the rewritten body to OpenAI.

  • Transport or parse failure → upstream.error
  • OpenAI status other than 200 is passed through. Decision is recorded as allow, check upstream. It is not a control block.

403 budget

OpenAI is not called. A live OpenAI error is not a 403 from this proxy.

7

Charge, then scan the answer

Tokens are usage.total_tokens, or len(assistant) // 4 when usage is missing. USD is tokens * models[model].usd_per_1k / 1000. The sum is written to budget.json with os.replace before the output can block.

Output spans come from choices[].message. Content is target output. Tool-call arguments are tool_args again. The same three checks run. A redact rewrites the OpenAI body in place.

Output Jev runs only on output spans whose cheap check is still Allow. A redacted or blocked span is not sent. tool_args stay out.

403 after the charge

A blocked answer still keeps the token cost on the audit line. The client receives 403, not the model text.

8

Return, and always audit

A pass returns the OpenAI status and body, with redacted spans already replaced. A block returns 403 and {"error": {"code", "type": "control_layer"}}.

The line is time, agent, model, tool names, decision (allow, redact, or block), check, tokens, USD, latency, and Jev scores when Jev ran. GET / polls GET /v1/report every 2 seconds. GET /v1/audit/export returns the file.

One line per request

Pass, redact, block, and an OpenAI error each write a line.

What each target is allowed to do

Target Where the text comes from Cheap checks Jev
prompt Message content that is not a tool result email, secret, signatures for this target After redact. All prompts joined. One call.
tool_result role: tool content Same three After redact. One call per result.
tool_args function.arguments string Same three. This is where exec, pickle, and model_host fire. Never.
output choices[].message.content Same three, after the charge Only when the cheap check left the span as Allow.

fold() across spans returns the first Block. Otherwise it merges every Redact. Otherwise Allow. Inside one span the next check runs on the already rewritten string, so a later signature cannot see a value an earlier row already replaced.
